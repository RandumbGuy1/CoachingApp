# Executive Summary
The Coaching App is my solution to allow coaches to create their own private gym coaching groups and manage a roster of clients.
Clients will be able to join groups and send their coaches any necessary training info

## Tech Stack
- ASPCore .NET
- Angular + Tailwind
- SQL Server + Docker Containers

## Role Structure
- Website Admin's: The development team
- Coaches: Personal trainers, normally a paid tier
- Clients: Trainees, a free tier

## Features for Clients
- Can set Bodyweight and Strength goals

- Create/Save Workout Plans
- Create/Save Warmup Routines

- Run and Log workouts in real time
  - Enter reps/weight each set
  - Stopwatch 
  - Superset Support
  - Drop set Support
- Create notes on individual workouts

- Auto set goals to aim for during the workout based on previous data

- View workout logs on graph for progression
- Exercise Glossary
- Clients given ranks based on everyone else in the coaching group (bronze to iridium)

- Can select from coaches template programs

## Features for Coaches
- Everything a Client can do
- Create template programs for client groups
- Edit exercise glossary
- View forms clients responded with
- View training programs and logs of clients
- Send form completion requests to clients
- Edit routines of clients
- Add notes to clients workouts
